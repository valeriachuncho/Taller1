### Problema 1
**Sincronización de Sensores**

Descripción: Simula dos sensores que emiten valores periódicos:

- Sensor1: Rango [20°C, 30°C], cada 1 segundo.
- Sensor2: Rango [30°C, 40°C], cada 1.5 segundos.
- Usa zip para combinar los valores de ambos sensores en un solo flujo.
- Detén el flujo después de 10 pares de valores.
- Genera una alerta si la diferencia absoluta entre las lecturas de Sensor1 y Sensor2 es mayor a 5°C.
  

```mathematica
Sensor1: 22°C, Sensor2: 27°C, Difference: 5°C
Sensor1: 24°C, Sensor2: 34°C, Difference: 10°C
🚨 ALERT! Significant difference detected: 10°C
```
## Codigo Scala
```scala

package segundoBimestre.semana9



import rx.lang.scala.Observable
import scala.util.Random
import scala.concurrent.duration._

object sincronizacionSensores extends App {

  val sensor1 = Observable.interval(1.second).map(_ => Random.between(20, 30))
  val sensor2 = Observable.interval(1.5.second).map(_ => Random.between(30, 40))

  sensor1.zip(sensor2)// esperfa que llegue los dos datos
    .take(10)
    .subscribe(
      onNext = { case (temp1, temp2) =>
        val diferencia= math.abs(temp1-temp2)
        println(s"Sensor1: $temp1°C, Sensor2: $temp2°C,Diferencia :$diferencia")
        if(diferencia> 5)
          println(s"🚨 ALERT! Significant difference detected: $diferencia°C")
      },
      onError = e => println(s"Error: ${e.getMessage}"),
      onCompleted = () => println("completed!")
    )

  
  Thread.sleep(16000)
}

```

### Problema 2
**Sistema de Alerta Complejo**

Descripción: Simula tres sensores que emiten datos periódicos:

- Sensor1: Temperatura (20°C a 30°C).
- Sensor2: Humedad (40% a 60%).
- Sensor3: Presión (950 hPa a 1050 hPa).
- Combina los datos de los tres sensores y detecta si alguna de las métricas está fuera de rango.
- Detén el flujo después de 20 combinaciones.

```yaml
Temperature: 22°C, Humidity: 50%, Pressure: 970 hPa
Temperature: 25°C, Humidity: 42%, Pressure: 1055 hPa
🚨 ALERT! Pressure out of range: 1055 hPa
...
```
```scala
package segundoBimestre.semana9

import rx.lang.scala.Observable
import scala.util.Random
import scala.concurrent.duration._

object AlertaCompleja extends App {


  val temperatura = Observable.interval(1.second).map(_ => Random.between(20, 30))
  val humedad     = Observable.interval(1.second).map(_ => Random.between(40, 60))
  val presion     = Observable.interval(1.second).map(_ => Random.between(950, 1050))


  temperatura
    .zip(humedad)
    .zip(presion)
    .take(20)
    .subscribe(
      onNext = { case ((temp, hum), pres) =>

        println(s"Temp: $temp°C, Hum: $hum%, Presión: $pres hPa")


        if (temp < 20 || temp > 30)
          println(s"🚨 ALERT! Temperatura fuera de rango: $temp°C")

        if (hum < 40 || hum > 60)
          println(s"🚨 ALERT! Humedad fuera de rango: $hum%")

        if (pres < 950 || pres > 1050)
          println(s"🚨 ALERT! Presión fuera de rango: $pres hPa")
      },

      onError = e => println(s"Error: ${e.getMessage}"),
      onCompleted = () => println("Stream completed!")
    )


  Thread.sleep(40000)
}
```
